# 算法（第 4 版）测验

## 第 1 章测验（检查点）

### Q1.（单选）二分查找要求输入数组满足什么前提？
- A. 元素全不同  B. 已排好序  C. 元素个数为 2 的幂  D. 元素为整数
**答案**：B
**解析**：二分查找靠"中间值排除一半"，前提是左边全小、右边全大，即数组有序。

### Q2.（单选）栈的进出规则是？
- A. 先进先出  B. 后进先出  C. 随机存取  D. 只进不出
**答案**：B
**解析**：栈 LIFO，像弹夹最后压入的最先打出。

### Q3.（单选）倍率实验中 t(2N)/t(N) 趋近 4，算法是几阶？
- A. 线性  B. 二阶  C. 三阶  D. 对数
**答案**：B
**解析**：时间 ∝ N^b，翻倍后比值 2^b=4 → b=2，即 O(N²)。

### Q4.（填空）加权 quick-union 中"加权"指记录______，把小树挂到大树根下。
**答案**：树的大小
**解析**：sz[] 记录每树节点数，小树并入大树，防退化成链。

## 第 2 章测验（检查点）

### Q5.（单选）插入排序的交换次数等于数组中什么？
- A. 元素总数  B. 倒置数量  C. 逆序对的一半  D. 最大值
**答案**：B
**解析**：每消除一个倒置恰好一次交换，故交换次数=倒置数。

### Q6.（单选）归并排序最坏比较次数约为？
- A. N  B. N log N  C. N²  D. 2^N
**答案**：B
**解析**：命题 H，归并最坏 ~N lg N，已触比较排序下界。

### Q7.（单选）快速排序平均比较次数约为？
- A. N  B. 1.39 N lg N  C. N²  D. 2N
**答案**：B
**解析**：~2N ln N ≈ 1.39 N lg N，只比最好情况多 39%。

### Q8.（多选）下列哪些排序是稳定的？
- A. 选择排序  B. 插入排序  C. 归并排序  D. 堆排序
**答案**：B, C
**解析**：插入、归并稳定；选择、堆排序不稳定。

## 第 3 章测验（检查点）

### Q9.（单选）随机 N 键构造的 BST，平均查找命中约为？
- A. log N  B. 1.39 lg N  C. N  D. N²
**答案**：B
**解析**：命题 C，~2 ln N ≈ 1.39 lg N。

### Q10.（单选）红黑树 N 节点的高度上界是？
- A. lg N  B. 2 lg N  C. N  D. N²
**答案**：B
**解析**：命题 G，红黑树高 ≤ 2 lg N。

### Q11.（单选）散列表线性探测要求装载因子 α 控制在？
- A. ≤ 1/2  B. ≤ 1  C. ≤ 2  D. 任意
**答案**：A
**解析**：α=N/M ≤ 1/2，否则探测链过长。

### Q12.（单选）散列表为什么不支持 rank/select？
- A. 速度慢  B. 散列打乱键顺序，无有序结构  C. 内存不够  D. 键不可比较
**答案**：B
**解析**：散列把键映射到槽，破坏了键的有序性。

## 第 4 章测验（检查点）

### Q13.（单选）为什么 BFS 能求最短路径？
- A. 它用栈  B. 按距离从小到大访问，首次到达即最短  C. 它遍历所有边  D. 它递归
**答案**：B
**解析**：BFS 波纹式扩散，先到的层距离短。

### Q14.（单选）切分定理说横切边中哪条必入 MST？
- A. 最长的  B. 权重最小的  C. 任意一条  D. 中间的
**答案**：B
**解析**：最小横切边必属 MST，是 Prim/Kruskal 的基石。

### Q15.（单选）Dijkstra 算法要求什么前提？
- A. 图是 DAG  B. 边权非负  C. 图无环  D. 顶点数为偶
**答案**：B
**解析**：边权非负，否则锁定后还可能出现更短路。

### Q16.（填空）Kruskal 用______判断两端是否已连通。
**答案**：并查集
**解析**：并查集近常数判断连通，配合边排序。

## 第 5 章测验（检查点）

### Q17.（单选）LSD 字符串排序要求字符串满足？
- A. 变长  B. 等长  C. 全相同  D. 为整数
**答案**：B
**解析**：LSD 从最右位逐位分桶，前提是等长。

### Q18.（单选）KMP 相对暴力查找的关键改进是？
- A. 更快的散列  B. 失配不回退文本指针  C. 用队列  D. 递归
**答案**：B
**解析**：KMP 用 DFA 决定模式指针位置，不回退 i。

### Q19.（单选）霍夫曼编码中频率高的字符编码？
- A. 更长  B. 更短  C. 相同  D. 随机
**答案**：B
**解析**：高频字符离根近，路径短，编码短。

## 综合测验（多章联考）

### Q20.（单选）下列哪种组合能正确描述"先排序再二分查找"？
- A. 归并排序 O(N log N) + 二分 O(log N)
- B. 快排 O(N²) + 二分 O(N)
- C. 堆排序 O(N) + 二分 O(log N)
- D. 插入 O(N) + 二分 O(1)
**答案**：A
**解析**：归并 N log N 保证，二分 log N；其余成本配错。

### Q21.（多选）下列哪些结构"查找最坏不是 O(log N)"？
- A. 普通 BST  B. 红黑树  C. 散列表(碰撞)  D. 有序数组
**答案**：A, C
**解析**：BST 有序插入退化 O(N)；散列碰撞链 O(N)。红黑树、有序数组有对数保证。

### Q22.（单选）要在内存极紧的实时系统中排 10^7 个元素且要 O(N log N) 最坏保证，选？
- A. 快速排序  B. 堆排序  C. 归并排序  D. 选择排序
**答案**：B
**解析**：堆排序原地 O(1) 额外空间 + O(N log N) 最坏保证。

## 最终检验（项目式任务）

**任务**：设计一个"城市连通与导航系统"，整合本书多章知识：
1. 读入 N 个城市和 M 条带权道路（无向图）；
2. 用 Kruskal（并查集）求最小生成树，输出总修路成本；
3. 用 Dijkstra 求任一城市到其他所有城市的最短距离；
4. 用符号表（散列）实现"城市名 → 城市编号"的字典；
5. 分析各步复杂度并写出选型理由。

**评分要点**：
- 正确用并查集实现 Kruskal（连通判断 + 收 V-1 条边）；
- Dijkstra 用优先队列、松弛规则正确；
- 符号表 put/get 抽象干净；
- 复杂度分析与 cheatsheet 一致（Kruskal E log E、Dijkstra E log V）；
- 能解释"为什么 MST 不是最短路径树"。
