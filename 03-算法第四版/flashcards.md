# 算法（第 4 版）抽认卡

## 第 1 章
### 卡片：二分查找的前提和复杂度？
- **背面**：前提是数组已排序；每次砍一半，最多 ⌊log₂N⌋+1 次比较，对数级别 O(log N)。
- **标签**：查找, 二分
- **章节**：ch01a

### 卡片：递归的两条铁律？
- **背面**：① 必须有基准条件（不再自我调用）；② 子问题与父问题不能有交集。
- **标签**：递归
- **章节**：ch01a

### 卡片：ADT（抽象数据类型）是什么？
- **背面**：数据 + 一组允许的操作；只露 API 藏内部表示（封装）。
- **标签**：ADT, 封装
- **章节**：ch01b

### 卡片：栈和队列的进出规则？
- **背面**：栈 LIFO（后进先出，像弹夹）；队列 FIFO（先进先出，像排队）。
- **标签**：栈, 队列
- **章节**：ch01c

### 卡片：动态数组为什么满了要翻倍、空了缩半？
- **背面**：平摊成本常数；缩容阈值 1/4 而非 1/2，防扩容缩容抖动。
- **标签**：均摊, 动态数组
- **章节**：ch01c

### 卡片：增长数量级七兄弟是哪些？
- **背面**：1 / log N / N / N log N / N² / N³ / 2^N。
- **标签**：复杂度
- **章节**：ch01d

### 卡片：倍率实验 t(2N)/t(N)→8 说明几阶？
- **背面**：三阶 O(N³)，因为 2^b=8 → b=3。
- **标签**：复杂度, 倍率
- **章节**：ch01d

### 卡片：加权 quick-union 的树高保证？
- **背面**：任意节点深度 ≤ lg N（命题 H）。
- **标签**：并查集
- **章节**：ch01e

### 卡片：路径压缩在哪一步做？
- **背面**：find 爬到根后，把路径上节点直接指向根。
- **标签**：并查集
- **章节**：ch01e

## 第 2 章
### 卡片：插入排序的交换次数等于什么？
- **背面**：数组中倒置（逆序对）的数量。
- **标签**：排序, 插入
- **章节**：ch02a

### 卡片：选择排序要多少次交换？
- **背面**：N-1 次（每轮最多换一次），比较 ~N²/2。
- **标签**：排序, 选择
- **章节**：ch02a

### 卡片：希尔排序为什么用递减 h？
- **背面**：大间隔让元素远距离就位，小间隔收尾时数组已基本有序。
- **标签**：排序, 希尔
- **章节**：ch02a

### 卡片：归并排序最坏比较次数？
- **背面**：~N lg N（命题 H），空间 O(N)。
- **标签**：排序, 归并
- **章节**：ch02b

### 卡片：基于比较的排序下界是？
- **背面**：~N lg N 次比较（决策树叶子 ≥ N!）。
- **标签**：排序, 下界
- **章节**：ch02b

### 卡片：快排平均比较次数？
- **背面**：~2N ln N ≈ 1.39 N lg N。
- **标签**：排序, 快排
- **章节**：ch02c

### 卡片：快排最坏情况及对策？
- **背面**：输入已有序时 O(N²)；对策是先随机打乱。
- **标签**：排序, 快排
- **章节**：ch02c

### 卡片：堆的数组下标关系？
- **背面**：节点 i 父亲 i/2，孩子 2i、2i+1。
- **标签**：堆, 优先队列
- **章节**：ch02d

### 卡片：堆排序总复杂度？
- **背面**：O(N log N)，原地 O(1) 额外空间。
- **标签**：排序, 堆排序
- **章节**：ch02d

### 卡片：Java 对原始类型和引用类型各用什么排序？
- **背面**：原始类型三向快排；引用类型归并（要稳定）。
- **标签**：排序, 选型
- **章节**：ch02e

## 第 3 章
### 卡片：符号表的核心两个操作？
- **背面**：put(key, value) 存入、get(key) 取值。
- **标签**：符号表
- **章节**：ch03a

### 卡片：有序数组实现符号表，get/put 各多快？
- **背面**：get O(log N)（二分）；put O(N)（搬移）。
- **标签**：符号表, 二分
- **章节**：ch03a

### 卡片：BST 的核心性质？
- **背面**：左子树键 < 根键 < 右子树键（中序遍历升序）。
- **标签**：BST
- **章节**：ch03b

### 卡片：随机 BST 平均查找？
- **背面**：~2 ln N ≈ 1.39 lg N（命题 C）。
- **标签**：BST
- **章节**：ch03b

### 卡片：红黑树高度上界？
- **背面**：≤ 2 lg N（命题 G）。
- **标签**：红黑树
- **章节**：ch03c

### 卡片：红黑树的红链接代表什么？
- **背面**：两个节点共同构成一个 3-节点（2-3 树的编码）。
- **标签**：红黑树
- **章节**：ch03c

### 卡片：散列函数理想性质？
- **背面**：计算快 + 分布均匀。
- **标签**：散列
- **章节**：ch03d

### 卡片：线性探测装载因子要求？
- **背面**：α = N/M ≤ 1/2。
- **标签**：散列
- **章节**：ch03d

### 卡片：散列表为什么不支持 rank？
- **背面**：散列打乱键顺序，无有序结构。
- **标签**：散列
- **章节**：ch03d

## 第 4 章
### 卡片：DFS 和 BFS 各用什么结构？
- **背面**：DFS 栈（递归）；BFS 队列。
- **标签**：图遍历
- **章节**：ch04a

### 卡片：为什么 BFS 能求最短路径？
- **背面**：按距离从小到大访问，首次到达即最短。
- **标签**：图遍历, 最短路
- **章节**：ch04a

### 卡片：邻接表空间复杂度？
- **背面**：O(V+E)。
- **标签**：图
- **章节**：ch04a

### 卡片：拓扑排序适用于什么图？
- **背面**：DAG（有向无环图）。
- **标签**：有向图, 拓扑
- **章节**：ch04b

### 卡片：强连通的定义？
- **背面**：两顶点互相可达（双向）。
- **标签**：有向图
- **章节**：ch04b

### 卡片：切分定理内容？
- **背面**：横切边中权重最小的那条必入 MST。
- **标签**：MST
- **章节**：ch04c

### 卡片：Kruskal 用什么判连通？
- **背面**：并查集。
- **标签**：MST, Kruskal
- **章节**：ch04c

### 卡片：Dijkstra 的前提和复杂度？
- **背面**：边权非负；E log V（优先队列）。
- **标签**：最短路径
- **章节**：ch04d

### 卡片："松弛"一条边做什么？
- **背面**：若经 v 到 w 更短，更新 distTo[w] 和 edgeTo[w]。
- **标签**：最短路径
- **章节**：ch04d
