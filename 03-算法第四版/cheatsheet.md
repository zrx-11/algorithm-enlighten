# 速查表

## 增长数量级七兄弟
| 量级 | 函数 | 典型算法 |
|---|---|---|
| 常数 | 1 | 数组取值 |
| 对数 | log N | 二分查找 |
| 线性 | N | 遍历数组 |
| 线性对数 | N log N | 归并排序 |
| 平方 | N² | 选择/插入排序 |
| 立方 | N³ | ThreeSum |
| 指数 | 2^N | 穷举（第6章） |

## 排序算法成本总表
| 算法 | 平均 | 最坏 | 额外空间 | 稳定 |
|---|---|---|---|---|
| 选择排序 | ~N²/2 比较 | ~N²/2 | 1 | 否 |
| 插入排序 | ~N²/4 | N² | 1 | 是 |
| 希尔排序 | 突破平方(经验) | ？ | 1 | 否 |
| 归并排序 | N lg N | N lg N | N | 是 |
| 快速排序 | 1.39 N lg N | N² | lg N | 否 |
| 三向快排 | N(大量重复键) | N² | lg N | 否 |
| 堆排序 | 2N lg N | 2N lg N | 1 | 否 |

## 查找/树成本
| 结构 | 平均查找 | 最坏 |
|---|---|---|
| 无序链表 | O(N) | O(N) |
| 有序数组二分 | O(log N) | O(log N)（插入 O(N)） |
| 随机 BST | ~1.39 lg N | O(N) |
| 红黑树 | log N | ≤ 2 lg N |
| 散列表(拉链) | O(1) | O(N)（碰撞时） |

## 图算法成本
| 算法 | 时间 | 空间 |
|---|---|---|
| DFS / BFS | O(V+E) | O(V) |
| Prim | E log V | V |
| Kruskal | E log E | E+V |
| Dijkstra | E log V | V |

## 关键公式
- 二分查找最多比较：⌊log₂N⌋+1
- 归并排序比较：~N lg N
- 快排平均比较：~2N ln N ≈ 1.39 N lg N
- 加权 quick-union 树高：≤ lg N
- 红黑树高度：≤ 2 lg N
- 散列表装载因子：α = N/M ≤ 1/2

## Java 系统排序选择（原书）
- 原始数据类型（int/double…）：三向切分快速排序
- 引用类型（String…）：归并排序（要稳定）

## 常用步骤
- 二分查找：lo=0, hi=N-1, 每次 mid=(lo+hi)/2 砍一半
- Dijkstra：选未确定 distTo 最小 u → 松弛 u 出边
- Kruskal：边按权排序 → 并查集判连通 → 收 V-1 条
