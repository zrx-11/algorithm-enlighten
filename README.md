## 二、本地使用

1. 双击 `index.html` → 浏览器打开总学习手册（离线可用；Mermaid 图需要联网渲染，离线时显示源码+正文）。
2. 顶部标签切换《跨书总览》《Hello 算法》《算法图解》《算法 第四版》《算法导论》。
3. 左侧导航：学习路径 → 章节 → 概念 → 测验（综合 + 分章）→ 抽认卡 → 术语表 → 模式库 → 速查表。
4. 单独伴侣：侧栏「单独打开 … 学习伴侣 ↗」或直接打开各书目录下的 `*学习伴侣.html`。

## 三、部署到 GitHub Pages

### 步骤 1：把本包内容放进仓库根目录

解压后，将**本包内的全部文件/目录**（`index.html`、`index.md`、`README.md`、`.nojekyll`、`00-跨书总览/`、`01-hello算法/` 等）放到你的仓库**根目录**（不是子目录）。

```bash
# 假设仓库已 clone 到本地，<仓库目录> 替换为实际路径
cd <仓库目录>
# 将解压出的全部文件复制到当前目录后：
git add -A
git commit -m "算法四书总学习手册 + 四套学习伴侣"
git push origin main
```

### 步骤 2：开启 Pages

仓库页面 → **Settings → Pages** →
- **Source**：`Deploy from a branch`
- **Branch**：`main`，目录选 **`/ (root)`**
- 点击 **Save**

约 1–2 分钟后访问：

```
https://<你的用户名>.github.io/<仓库名>/
```

打开即为总学习手册（GitHub Pages 自动以根目录 `index.html` 为首页）。

> `.nojekyll` 已内置：告诉 Pages 关闭 Jekyll，原样托管全部静态文件（含中文文件名、`_build/` 等以下划线开头的目录）。

### 可选：用 GitHub Actions 自动部署

若希望每次 push 自动发布，可在仓库 `.github/workflows/pages.yml` 添加标准 Pages 工作流；本包为纯静态站点，直接用上面的「Deploy from a branch」最省事，无需 Actions。

## 五、说明与取舍

1. **体积**：仓库约 4.9 MB，主要是四套学习伴侣的内嵌数据与 `index.html`。GitHub Pages 上限 1 GB、单文件 100 MB，空间很宽裕。原始语料与扫描页截图已在上传前剥离；本地完整包约 13 MB，需要追溯时从交付包取。
2. **版权**：学习伴侣中的精讲、类比、图示、测验均为原创改写与教学化表达，可以公开；`_work/raw/` 原文与扫描页截图为制作过程留档，只在本地交付包中，没有上传。
3. **Mermaid**：图示通过 CDN 懒加载渲染；无网络时自动降级为源码显示，正文不受影响。
