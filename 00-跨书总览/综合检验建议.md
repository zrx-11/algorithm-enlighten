## 一、跨书整合题（4 道）

### 第 1 题：排序全家桶的「多书对比分析」

**题目**：给定 10⁷ 个待排数据，请你回答——
（a）如果它们全是范围 [0, 10⁶] 的整数，最快能多快？为什么这个速度不违反「比较排序下界」？
（b）如果它们是 Java 对象（要保持相等元素原顺序），该选哪种？为什么原始类型不选它？
（c）如果运行在内存极紧的实时系统，且要求最坏情况必须 O(n log n)，选哪种？它付出了什么代价？

**评分要点（满分 10）**：
- 答出「计数排序 O(n+k) 线性时间」+ 引用**导论第8章·线性时间排序**（2 分）
- 说清「比较排序下界 Ω(n log n)」出自**导论第8章**决策树证明，而计数排序不基于比较（2 分）
- 答出「Java 引用类型用归并，因为要稳定」+ 引用**四版第2章(2.5)·排序应用与选型**（2 分）
- 答出「原始类型用三向快排，因为稳定无所谓、常数更小」（2 分）
- 答出「内存紧 + 最坏 O(n log n) → 堆排序原地 O(1) 额外空间」+ 代价是「不稳定、常数比快排大」+ 引用**四版第2章(2.4)** 与**导论第6章**（2 分）

**涉及书目章节**：图解第2章（选择排序直觉）→ Hello 第11章（五维对比表）→ 四版第2章(2.1~2.5) → 导论第6/7/8章。

---

### 第 2 题：从「抽象数据类型」到「具体数据结构」的选择决策树

**题目**：业务方提了 5 个需求，你分别该选哪种数据结构？要求说清「为什么是它、为什么不是别的」。
1. 1000 万用户名，频繁判断「这个用户注册过没」，无序。
2. 同样的数据，但还要支持「查出当前排名第 5000 的用户是谁」。
3. 要按层来遍历一个社交网络的好友关系。
4. 要从海量日志里实时弹出「当前优先级最高」的任务。
5. 要维护动态连通性（两台服务器是否已在同一网络里），并支持合并。

**评分要点（满分 10）**：
- (1) 答「哈希表/集合 O(1)」，并说为什么不是有序数组二分（插入太贵）、不是链表（查找 O(n)）→ **Hello 第6章**、**图解第5章**（2 分）
- (2) 答「散列表不支持 rank，要平衡树/顺序统计树」，点出「散列把键顺序打乱了」→ **四版第3章(3.4)** quiz 原话、**导论第14章·数据结构的扩张**（顺序统计树）（2 分）
- (3) 答「BFS 用队列按层扩展」→ **图解第6章**、**Hello 第9章**、**导论第22章**（2 分）
- (4) 答「优先队列 = 堆」，Top-k 用大小 k 的小顶堆 O(n log k) → **Hello 第8章**、**四版第2章(2.4)**、**导论第6章**（2 分）
- (5) 答「并查集 union/find，路径压缩 + 按秩合并，近 O(α(n))」→ **四版第1章(1.5)**、**导论第21章**（2 分）

**一句话考点**：这道题考的是**选型决策树**——ADT（要什么操作）→ 具体结构（怎么实现）→ 复杂度代价。

### 第 3 题：最短路径的「负权」边界问题

**题目**：导航软件要给城市里最快路线。
（a）所有路段耗时都是正数，用什么？它为什么不能有负权边？
（b）某条「高速公路逆行入口」耗时被标成负数（惩罚），狄克斯特拉为什么会算错？该换成谁？
（c）如果要一次性算好全城任意两点的最快路线，又该用什么？复杂度多少？
（d）什么情况下「最短路径」根本不存在？

**评分要点（满分 10）**：
- (a) 狄克斯特拉，边权非负；「先定死最便宜节点」的前提被负权破坏 → **图解第7章**、**四版第4章(4.4)**（2.5 分）
- (b) 换 Bellman-Ford，O(VE)，容负权边 → **导论第24章**（2.5 分）
- (c) Floyd-Warshall 全点对，Θ(n³)；或 Johnson 重赋权 → **导论第25章**（2.5 分）
- (d) 图里存在「负权回路」时，绕圈越绕越短，最短路不存在 → **导论第24章**「负权回路」术语（2.5 分）

**考点**：同一个「找最短路」问题，权值的符号一变，算法全家桶就要换一套——这是跨书串起来的。

### 第 4 题：DP vs 贪心 vs 分治，什么时候用哪个？

**题目**：判断下列问题各该用什么策略，并说清为什么不是另外两个。
1. 爬楼梯：每次跨 1 或 2 阶，到第 n 阶有几种走法。
2. 零钱兑换：硬币面额 [1, 20, 50]，凑 60。
3. 归并排序。
4. n 皇后：列出所有合法摆法。
5. 活动选择：会议室不冲突地选最多活动。

**评分要点（满分 10）**：
- (1) DP：重叠子问题 + 最优子结构，dp[i]=dp[i-1]+dp[i-2] → **Hello 第14章**（2 分）
- (2) 必须 DP 不能贪心：[1,20,50] 凑 60 时贪心得 11 枚、最优 3 枚（20+20+20）→ **Hello 第15章**反例（2 分）
- (3) 分治：子问题独立不重叠（DP 是重叠的）→ **Hello 第12章**、**导论第4章**（2 分）
- (4) 回溯：要**列出所有解**而非求最优值，三动作尝试/回退/剪枝 → **Hello 第13章**（2 分）
- (5) 贪心：选结束最早的兼容活动，满足贪心选择性质 → **导论第16章**、**图解第8章**（2 分）

**考点**：四本书里最容易混的就是这四大策略。判据记一句话：**子问题重叠 → DP；要求列出全部解 → 回溯；子问题独立 → 分治；局部最优可推全局 → 贪心**。

## 二、建议复习节奏（间隔重复）

> 不要学完就扔。按下面的节点回头翻，忘得最慢。

| 节点 | 做什么 | 用什么材料 |
|---|---|---|
| **次日** | 重做当天章节的 quiz + flashcards，遮住答案口述 | 各书 `quiz.md`、`flashcards.md` |
| **第 3 天** | 只翻 `cheatsheet.md` 速查表，讲不出的标记出来重看对应章节 | 各书 `cheatsheet.md` |
| **第 7 天** | 跨书概念映射表里挑 5 个概念，说出四本书各自怎么讲 | `00-跨书总览/跨书概念映射表.md` |
| **第 30 天** | 做上面 4 道整合题里的 2 道，限时写思路 | 本文件 |
| **第 90 天** | 用本文件 4 道题完整自测一遍，对照评分要点打分 | 本文件 |

**小技巧**：每本书的 `flashcards.md` 就是为间隔重复准备的，按「次日/3天/7天」三张卡的节奏过，比重读整章高效得多。

## 三、进阶路线（三条分叉）

学完全套后，按你的目标选一条继续深入，别三条一起啃。

### 路线 A：竞赛（想打 ACM / LeetCode 冲分）
- **重点书**：Hello 算法（第12~15章 分治/回溯/DP/贪心）+ 导论（第15/16章）。
- **补什么**：图论里的**最大流**（导论第26章）、数论（导论第31章）是竞赛高频但 Hello/四版讲得浅。
- **怎么练**：把本文件第 2、4 题的选型直觉，拿到 OJ 上每类刷 10 道，重点练 DP 和图。

### 路线 B：工程（想进大厂写后端 / 做基础设施）
- **重点书**：算法第四版（第2章排序选型、第3章符号表/散列、第4章图）。
- **补什么**：并发、B 树（导论第18章，对应数据库索引）、字符串 Trie（四版第5章）。
- **怎么练**：用 Java 或 Python 手写一遍 HashMap、PriorityQueue、并查集，读 JDK/标准库源码对照。

### 路线 C：理论（想考研 / 读论文 / 读研）
- **重点书**：算法导论整本，尤其第3章渐近记号、第4章主方法、第17章摊还分析、第34/35章 NP 完全性。
- **补什么**：附录 A/B/C/D（求和、离散数学、概率、矩阵）要当工具书随时翻。
- **怎么练**：把导论每章的定理**自己重新证一遍**，而不是看一遍；用本文件第 1、3 题检验能不能把直觉讲成证明。
