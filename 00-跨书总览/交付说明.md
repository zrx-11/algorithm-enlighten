# 算法专项 · 点化学习系统 — 交付说明

> 本包把四本算法经典书籍「点化」成一套面向**零基础**学习者的完整自学系统：
> 每本书 = Markdown 知识库（章节精讲/概念页/术语表/模式库/速查表/测验/抽认卡）+ 单文件交互 HTML 学习伴侣，
> 外加一份跨书总览（推荐学习顺序 + 跨书概念映射 + 综合检验）。
> 全部内容为简体中文；《Hello 算法》以 Python 版为主语言。

## 二、每类文件是干什么的

| 文件/目录 | 用途 | 怎么用 |
|---|---|---|
| `*学习伴侣.html` | **单文件交互学习伴侣**：目录导航、全文搜索、测验即时反馈、抽认卡翻面+「认识/不熟」标记、进度 localStorage 持久、深色模式 | 浏览器直接打开（file:// 双击即可，无需联网/服务器）；学完一章在侧栏点下一章，进度自动保存 |
| `SKILL.md` | 每本书的学习总纲：全书心智模型图、拓扑序学习路径表、章节难度索引、前置缺口补讲表 | 学一本书前先读它，按「学习路径」表的顺序走 |
| `chapters/` | 每章一份**零基础精讲**：难度/学时/前置、学习目标、一句话核心、白话讲解（术语首现即定义）、图示+看图说明、类比+实例、常见误解、自测题（带答案与解析）、复习锚点 | 主学习材料，按路径顺序逐章精读，读完做章末自测题 |
| `concepts/` | 跨章核心概念页：一句话定义、为什么重要、图示、详解、常见误解、在书中的脉络 | 学到相关章节时点开；考前/复习时集中过一遍 |
| `glossary.md` | 术语表（白话定义 + 首次出现章节） | 遇到不懂的术语随手查 |
| `patterns.md` | 模式/框架库：作者的分析框架、决策规则、反模式 | 学完后提炼"套路"，刷题/面试前过一遍 |
| `cheatsheet.md` | 速查表：公式、复杂度、规则的高密度汇总 | 临考/编码时的快速参考 |
| `quiz.md` | 测验：各章检查点 + 综合测验 + 最终检验（项目式任务） | 每章自测题过关（≥80%）再进入下一章 |
| `flashcards.md` | 抽认卡（正面只放问题） | 配合 HTML 里的抽认卡功能做间隔重复（次日/3天/7天） |
| `manifest.json` | 结构化清单（章节/概念/术语/测验/卡片），是 HTML 组装的数据源 | 一般不需直接阅读；改内容后用它重新组装 HTML |
| `_work/` | **过程产物**：抽取的原始文本语料（`raw/`）、扫描版 PDF 的读图 PNG、构建/验证脚本、验证截图 | 追溯内容来源、复现构建、查看验证证据时使用；不影响正常学习 |

## 三、使用方法

### 1. 最简路径（只看 HTML）
打开任意一本的 `*学习伴侣.html` → 按侧栏「学习路径」顺序学 → 每章读精讲、做测验（即时判分）、用抽认卡复习 → 进度自动记住，下次打开接着学。

### 2. 完整路径（知识库 + HTML）
- 先读 `00-跨书总览/README.md`，按推荐顺序 **算法图解 → Hello 算法 → 算法第四版 → 算法导论** 逐本推进；
- 每本书：先 `SKILL.md` 看全局 → 按学习路径读 `chapters/` 对应章 → 章末自测题 → 概念页加深 → 抽认卡记忆；
- 学完一本用 `quiz.md` 的综合测验收尾；
- 四本学完后，做 `00-跨书总览/综合检验建议.md` 的 4 道跨书整合题完成最终检验。

### 3. 按需学习（不从头读）
用 `00-跨书总览/跨书概念映射表.md` 反查：想搞懂某个概念（如「动态规划」），看「最佳入门入口」列指向哪本书的哪一章，直接跳过去学；想验证严谨性再看对应书的高难章节。

## 五、制作过程备注（透明度说明）

- 本套系统由点化流程（book-enlighten）生成：文本抽取 → 结构拆解 → 概念/心智模型 → 章节精讲 → 记忆系统 → 组装 HTML → 六项验证。
- 制作期间执行环境重启过两次，中途确认停滞的子代理已终止并按「从已落盘产物继续」原则重建/续写（Hello 算法、算法图解、算法第四版三本为完整重建；算法导论为已写 23 章后从 ch24 续写至 39 章收官），已落盘的章节文件未重写。
- 验证过程中发现并修复了两处构建脚本缺陷（章节路由前缀剥离、Mermaid 离线渲染），修复后四本书全部复验通过；父代理另以独立脚本对四本 HTML 复核，全部通过。
- `_work/` 中的验证截图与脚本即为上述验证的证据留存。
