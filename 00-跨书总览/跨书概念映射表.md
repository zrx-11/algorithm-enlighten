# 跨书概念映射表

> 本表是「四本算法书」的对照表：**同一个概念，在每本书的哪一章讲、谁讲得最直觉、谁讲得最严谨，一查便知。**
> 所有章节号与标题均来自四本书各自 `manifest.json` 的真实章节，没有编造。
> 「—」表示这本书没有把它单列成章（可能完全没讲，也可能只是一笔带过）。
> 书名列简称：**图解**＝《算法图解》，**Hello**＝《Hello 算法》，**四版**＝《算法（第4版）》，**导论**＝《算法导论》。

## 怎么读这张表

- 想**第一次搞懂**某个概念 → 优先看「最佳入门入口」列指的那本书。
- 想**验证自己真懂了 / 应付考试面试** → 再去对应看导论或四版的严谨版。
- 同一概念四本书口径不同时，表后「重点概念对比块」展开说明，**不强行统一**。

## 重点概念对比块（口径差异展开）

### 对比块 1：大O 到底该怎么学？

- **图解第1章**：只教「看最糟情况、忽略常数」。你会算 `O(log n) < O(n) < O(n²)` 就够了。
- **Hello 第2章**：多了「空间复杂度」和「最坏/平均」的区分，背熟阶序口诀。
- **四版第1章(1.4)**：教你**实测**——输入翻倍，看时间比值 `t(2N)/t(N)`：趋近 4 就是 O(N²)，趋近 8 就是 O(N³)。
- **导论第3章**：严格区分 Θ（确界）、O（上界）、Ω（下界），还有小 o 是「严格小于」。
- **怎么衔接**：先用图解建立手感 → Hello 补空间维度 → 面试/工程用四版倍率法 → 写论文读导论的 Θ/O/Ω。

### 对比块 2：动态规划，为什么图解和导论差这么多？

- **图解第9章**：一张二维网格，背包逐行逐格填，字母不同时子串归 0、子序列取 max。完全直觉，不写状态方程。
- **Hello 第14章**：把直觉升级成三条铁律——重叠子问题、最优子结构、无后效性；0-1 背包一维数组要**倒序**遍历容量（防止覆盖上一行）。
- **导论第15章**：给你正式的状态定义 `c[i,j]`，讲矩阵链乘 O(n³)，强调 DP 两个适用条件缺一不可。
- **衔接关键句**：「网格」就是「dp 表」，「逐格填」就是「自底向上递推」。先看图解的网格，再回头看导论的 `c[i,j]`，会发现是同一张表。

### 对比块 3：狄克斯特拉 vs 最短路径全家桶

- **图解第7章**：手算四步——选最便宜节点 → 更新邻居 → 重复 → 回溯父节点。记住「负权边会让它失效」。
- **四版第4章(4.4)**：把它工程化成「松弛」操作 `if(d[u]+w(u,v)<d[v]) 更新`，用优先队列做到 E log V。
- **导论第24/25章**：补齐另外两家——Bellman-Ford 容负权边但 O(VE)；Floyd-Warshall 全点对 Θ(n³)；遇到负权回路要直接判定「最短路不存在」。
- **一句话选型**：边权都非负 → 狄克斯特拉；可能有负权 → Bellman-Ford；要所有点对 → Floyd-Warshall。

### 对比块 4：排序为什么要学四遍？

- **图解**：只会选择排序 O(n²) 和快速排序 O(n log n 平均)。
- **Hello 第11章**：一张表列五个维度——运行效率、原地、稳定、自适应、是否基于比较。
- **四版第2章**：给出 Java 真实选型——原始类型用三向快排，引用类型（要稳定）用归并；内存紧的实时系统用堆排序（原地 + O(N log N) 最坏保证）。
- **导论第6/7/8章**：先证明「基于比较的排序怎么都快不过 Ω(n log n)」，再教你打破它——计数排序、基数排序在键是小范围整数时能到线性时间。
- **衔接关键句**：前一本教「怎么写」，后一本教「什么时候不能更快、什么时候能更快」。
