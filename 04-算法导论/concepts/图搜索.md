# 图搜索（BFS 与 DFS）

- **难度**：基础 | **涉及章节**：第 22、24、26 章

## 一句话定义
**BFS 像水波纹一层层扩（队列），DFS 像走迷宫一条路走到黑（栈/递归）——两者都 O(V+E)，但给你不同的图结构信息。**

## 为什么重要
几乎所有图算法都是 BFS/DFS 的变体：BFS 求无权最短路、DFS 做拓扑排序和强连通分量、Dijkstra/Prim 在 BFS 骨架上换个优先队列。

## 图示
```mermaid
flowchart TD
    A[图 G=(V,E)] --> B{BFS 还是 DFS?}
    B -->|BFS 队列| C[按距离层扩展]
    C --> D[无权最短路: d[s,v]=层数]
    C --> E[层次图/广度树]
    B -->|DFS 栈| F[一条路走到黑, 回溯]
    F --> G[发现时间/完成时间]
    G --> H[拓扑排序: 按完成时间逆序]
    G --> I[强连通分量: 两次 DFS]
```
**看图说明**：BFS 用「队列」保证按层；DFS 用「栈+时间戳」暴露图的前后结构（拓扑、强连通）。

## 详解
- **BFS**：从 s 出发，先把 s 的所有邻居入队，再逐个扩展。每个顶点首次被发现时的 d 值就是到 s 的无权最短距离。O(V+E)。
- **DFS**：递归地沿一条路径走到死，再回溯。给每个顶点记发现时间 d 和完成时间 f。
- **拓扑排序**：DAG 上按 DFS 完成时间 f 从大到小输出。
- **强连通分量**：先在 G 上 DFS 得 f；再把边反转在转置图上按 f 降序 DFS，每次 DFS 树就是一个 SCC。

类比：BFS 像「广播」——信号一圈圈扩；DFS 像「翻阅家谱」——先把一支脉挖到底，再退回来翻下一支。失效边界：BFS 只能求无权最短路（或权全相等）；有权图要用 Dijkstra。

## 常见误解
- 别以为「BFS 和 DFS 复杂度不同」——实际上都是 O(V+E)，差别在「得到的信息」。
- 别以为「拓扑排序只能 DFS」——实际上也能反复找入度为 0 的顶点（Kahn 算法）。
