# 最小生成树

- **难度**：进阶 | **涉及章节**：第 23、16、21 章

## 一句话定义
**在带权无向图里选 |V|−1 条边把所有顶点连起来、总权最小；切分性质保证「每次选最轻跨切口」的贪心一定对。**

## 为什么重要
MST 是「连通所有点且成本最小」的抽象——电路布线、网络架设、聚类都归约到它。Kruskal 与 Prim 两种贪心实现是「并查集」和「优先队列」两种数据结构的经典练兵。

## 图示
```mermaid
flowchart TD
    A[带权无向图] --> B[切分性质: 最轻跨切口必在某棵 MST]
    B --> C{怎么选?}
    C -->|按权排序+并查集| D[Kruskal: O(E lg V)]
    C -->|从根长树+优先队列| E[Prim: O(E lg V), 斐波那契堆 O(E+V lg V)]
```
**看图说明**：两种算法都靠切分性质；Kruskal 全局排边，Prim 从一棵树向外长。

## 详解
- **生成树**：连通所有顶点、|V|−1 条边、无环。
- **切分性质（定理 23.1）**：A 是某棵 MST 的边集、切分尊重 A，则横跨切分的最轻边对 A 安全。
- **Kruskal**：边按权排序，用并查集判断两端是否同根，不同根就加边。
- **Prim**：从根出发，优先队列维护「不在树的顶点到树的最短边」，每次拉最轻的进来。

类比：MST 像「修村村通公路」——每次在已通路区和未通路区之间选最便宜的一段。失效边界：MST 只保证总权最小，不保证任意两点间路径最短（那是最短路）。

## 常见误解
- 别以为「MST 给出任意两点最短路」——实际上不保证。
- 别以为「Prim 必须从某特定点出发」——实际上任意点作根都行。
