# 速查表

## 算法复杂度速查

| 算法 | 最坏 | 期望 | 备注 |
|---|---|---|---|
| 插入排序 | Θ(n²) | — | 小数据/基本有序快 |
| 归并排序 | Θ(n lg n) | — | 稳定，需 O(n) 额外空间 |
| 堆排序 | O(n lg n) | — | 原地，不稳定 |
| 快速排序 | Θ(n²) | Θ(n lg n) | 随机化枢轴 |
| 计数排序 | O(n+k) | — | 数据范围 [0,k] |
| 基数排序 | O(d(n+k)) | — | d 位、每位 [0,k] |
| 顺序统计(最坏线性) | Θ(n) | — | BFPRT 选中位数 |
| BFS / DFS | O(V+E) | — | — |
| 拓扑排序 | O(V+E) | — | DAG |
| Kruskal | O(E lg V) | — | 并查集 |
| Prim (二叉堆) | O(E lg V) | — | 斐波那契堆 O(E+V lg V) |
| Bellman-Ford | O(VE) | — | 容负权边 |
| Dijkstra | O(E lg V) | — | 不容负权边 |
| Floyd-Warshall | Θ(n³) | — | 所有点对 |
| Johnson | O(V² lg V+VE) | — | 稀疏图+负权边 |
| Edmonds-Karp | O(VE²) | — | BFS 增广 |
| Push-relabel | O(V³) | — | 前置重贴标签 |

## 主方法三情况（T(n)=aT(n/b)+f(n)）

| 情况 | 条件 | 解 |
|---|---|---|
| 1 | f(n)=O(n^{log_b a−ε}) | Θ(n^{log_b a}) |
| 2 | f(n)=Θ(n^{log_b a}) | Θ(n^{log_b a}·lg n) |
| 3 | f(n)=Ω(n^{log_b a+ε}) 且正则 | Θ(f(n)) |

## 常用求和

| 求和 | 结果 |
|---|---|
| Σ_{k=1}^{n} k | n(n+1)/2 = Θ(n²) |
| Σ_{k=1}^{n} k² | n(n+1)(2n+1)/6 = Θ(n³) |
| Σ_{k=0}^{n} xᵏ (x≠1) | (x^{n+1}−1)/(x−1) |
| Σ_{k=0}^{∞} xᵏ (\|x\|<1) | 1/(1−x) |
| Hₙ = Σ1/k | Θ(lg n) |

## 数论工具

| 工具 | 结论 |
|---|---|
| gcd(a,b) | 欧几里得 gcd(b, a mod b)，O(lg a) |
| 模逆元 | 扩展欧几里得求 ax+by=gcd，gcd=1 时 x 即逆元 |
| 快速幂 | aᵇ mod n，O(lg b) 次模乘 |
| CRT | n=∏nᵢ 互素 ⇔ 模 n 与模各 nᵢ 一一对应 |
| RSA | 公钥 (e,n) 加密 mᵉ；私钥 d 解密 cᵈ |
