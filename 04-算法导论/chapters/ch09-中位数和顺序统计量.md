# 第 9 章：中位数和顺序统计量

- **难度**：★★☆ | **预估学时**：2 小时 | **前置**：第 5、7 章

## 学习目标
学完本章，你能：
1. 用成对比较在 3⌊n/2⌋ 次比较内同时找到最小值和最大值。
2. 写出 RANDOMIZED-SELECT 的伪代码，说出它期望 Θ(n) 的原因。
3. 了解最坏情况线性时间选择算法（BFPRT/中位数的中位数）的思想。

## 一句话核心
**「找第 i 小」不必先排序——快排的 PARTITION 只要递归一边，期望 Θ(n) 就能选中位数。**

## 零基础讲解

### 概念 1：顺序统计量（order statistic）（难度：基础）
**第 i 个顺序统计量**就是 n 个元素中第 i 小的元素。最常见的是最小值（i=1）、最大值（i=n）、中位数（i≈⌈n/2⌉）。

### 概念 2：同时找最小与最大（难度：基础）
 naive 做法：最小值 n-1 次比较、最大值 n-1 次比较，共 2n-2 次。书中优化（书页 §9.1 已核对）：**成对处理**——先把两个元素互相比，小的去跟当前最小值比、大的去跟当前最大值比。每对只花 3 次比较。n 为奇/偶数初值不同，但总比较次数至多 **3⌊n/2⌋**。

### 概念 3：RANDOMIZED-SELECT（难度：进阶）
思路：像快排 PARTITION，但**只递归主元所在的一边**——因为第 i 小要么在左、要么在右、要么就是主元。
```
RANDOMIZED-SELECT(A, p, r, i)
1  if p == r: return A[p]
2  q = RANDOMIZED-PARTITION(A, p, r)
3  k = q - p + 1          // 主元 A[q] 是第 k 小
4  if i == k: return A[q]
5  if i < k: return RANDOMIZED-SELECT(A, p, q-1, i)
6  else: return RANDOMIZED-SELECT(A, q+1, r, i-k)
```
**关键**：不像快排递归两边，只递归一边——期望运行时间 **Θ(n)**（书中 §9.2 证明）。对比：快排期望 Θ(n lg n)，因为它两边都要排。

### 概念 4：最坏线性时间（SELECT，BFPRT）（难度：高难，了解思想）
RANDOMIZED-SELECT 最坏仍是 Θ(n²)（总切偏）。书中 §9.3 给出最坏也线性的算法「中位数的中位数」：把 n 个元素 5 个一组分组、每组取中位数、再对这些中位数递归取中位数，以它作主元——保证每轮至少 3n/10 左右被切走，递归式 T(n) ≤ T(⌈n/5⌉) + T(7n/10) + Θ(n) ⇒ **T(n) = Θ(n)**。这就是著名的 BFPRT 算法。工程中很少用（常数太大），但理论上证明「选择可以最坏线性」。

**看图说明**：与快排最大的区别——只走一条分支，所以期望代价不是 n lg n 而是 n。

## 类比与实例
- **类比**：在一堆报名者里挑「第 10 名」，不必把所有人都排名——随便挑一人当标杆，比他小的放左边、大的放右边，看「第 10」在左还是右，继续在那一边找。**失效边界**：若每次标杆都是最大或最小（坏运气），就退化到 Θ(n²)；随机化主元正是为了防这个。
- **实例**：A = ⟨3, 2, 9, 0, 7, 5, 4, 8, 6, 1⟩ 找第 5 小。某次 PARTITION 后主元 k=4，i=5>k ⇒ 到右半找第 i-k=1 小。

## 常见误解
- **别以为「选中位数必须先排序」**——实际上 RANDOMIZED-SELECT 期望 Θ(n)，比排序的 Θ(n lg n) 快。
- **别以为「RANDOMIZED-SELECT 最坏也快」**——实际上它期望 Θ(n)，最坏 Θ(n²)；想要最坏线性得用 BFPRT，但常数巨大不实用。
- **别以为「找最小最大要 2n-2 次比较」**——实际上成对比较只要 3⌊n/2⌋ 次。

## 自测题（答案）
1. （单选）RANDOMIZED-SELECT 的期望运行时间是？（答案：B；解析：只递归一边，书中证明 Θ(n)）
   - A. Θ(n lg n)   B. Θ(n)   C. Θ(n²)   D. Θ(lg n)
2. （单选）同时找最小和最大值，最优比较次数约为？（答案：C；解析：成对比较 3⌊n/2⌋）
   - A. 2n   B. n   C. 3⌊n/2⌋   D. n lg n
3. （填空）BFPRT 算法通过「中位数的中位数」选主元，保证最坏运行时间为 Θ(__)。（答案：n；解析：T(n)=Θ(n)）
4. （简答）RANDOMIZED-SELECT 为什么比快排快一个量级？（答案：快排要递归排序左右两半，总代价 n lg n；SELECT 只在包含第 i 小的那一半递归，每轮丢弃一半，期望总代价 n + n/2 + n/4 + … = Θ(n)）

## 复习锚点
- 顺序统计量 = 第 i 小；最小/最大/中位数。
- 成对比较找最值：3⌊n/2⌋ 次。
- RANDOMIZED-SELECT 期望 Θ(n)，只递归一边。
- BFPRT：最坏 Θ(n)，但常数大不实用。
