# 第 4 章：分治策略

- **难度**：★★★ | **预估学时**：3.5 小时 | **前置**：第 2 章、第 3 章

## 学习目标
学完本章，你能：
1. 对 T(n) = aT(n/b) + f(n) 形式的递归式，用主方法三种情况直接读出结果。
2. 用递归树估算一个递归式的上界，再用代入法验证。
3. 用分治解最大子数组问题，并说出它与暴力法 Θ(n²) 的复杂度对比。

## 一句话核心
**分治递归式 T(n) = aT(n/b) + f(n) 的解由「子问题代价」与「合并代价 f(n)」谁占主导决定——主方法给了三档查表法。**

## 零基础讲解

### 概念 1：最大子数组问题（难度：进阶）
股价每日变动序列里，「哪天买、哪天卖赚钱最多」等价于求**变动数组** A 的连续子数组，使其和最大。
- 暴力法：枚举所有 i≤j，O(n²) 对，每对求和 O(n)，总 Θ(n³)。
- 分治法：把 A[low..high] 从 mid 切开。最大子数组只可能在三种位置：
  1. 完全在左半 A[low..mid]；
  2. 完全在右半 A[mid+1..high]；
  3. **跨越中点**（low ≤ i ≤ mid < j ≤ high）。
- 跨中点情况用 FIND-MAX-CROSSING-SUBARRAY：左半从 mid 向左扫求最大和 left-sum，右半从 mid+1 向右扫求最大和 right-sum，合并即得。这一步 Θ(n)。
- 递归式 T(n) = 2T(n/2) + Θ(n) ⇒ **Θ(n lg n)**。

### 概念 2：Strassen 矩阵乘法（难度：高难）
两个 n×n 矩阵朴素乘法 Θ(n³)。Strassen 的巧思：把 4 个 n/2 子矩阵的 8 次乘法换成 **7 次**（用中间矩阵 M₁…M₇ 的加减组合），递归式 T(n) = 7T(n/2) + Θ(n²)。用主方法读出 ⇒ **Θ(n^lg7) ≈ Θ(n^2.81)**。

### 概念 3：求解递归式的三种方法（难度：进阶）
1. **代入法**：猜测一个界，用数学归纳法证明常数可行。例：证明 T(n)=2T(⌊n/2⌋)+n 为 O(n lg n)，猜 T(n) ≤ c n lg n，代入验证 c 的选择。
2. **递归树**：把递归式逐层展开成树，每层代价写出来求和。书中例子 T(n)=T(n/3)+T(2n/3)+cn：树高约 log_{3/2} n，每层代价 cn，总 cn·log n = O(n lg n)（书页已核对该推导）。
3. **主方法**：直接套公式（见下）。

### 概念 4：主定理（定理 4.1）（难度：进阶）
对 a ≥ 1、b > 1，T(n) = aT(n/b) + f(n)（n/b 取整不影响渐近）：

| 情况 | 条件（与 n^log_b a 比较） | 结论 |
|---|---|---|
| 1 | f(n) = O(n^{log_b a − ε})，ε>0（子问题代价主导） | T(n) = Θ(n^{log_b a}) |
| 2 | f(n) = Θ(n^{log_b a})（两者持平） | T(n) = Θ(n^{log_b a} · lg n) |
| 3 | f(n) = Ω(n^{log_b a + ε})（合并代价主导），且满足正则条件 a·f(n/b) ≤ c·f(n)，c<1 | T(n) = Θ(f(n)) |

**记忆锚**：先算 n^{log_b a}（所有子问题加起来的总代价层），再跟 f(n) 比大小：小 → 子问题赢（情况1）；平 → 乘 lg n（情况2）；大 → f(n) 赢（情况3）。

**例**：归并 T(n)=2T(n/2)+Θ(n)：log_b a = log_2 2 = 1，n^1 = n 与 f(n)=n 持平 ⇒ 情况 2 ⇒ Θ(n lg n)。
**例**：Strassen T(n)=7T(n/2)+Θ(n²)：log_2 7 ≈ 2.81，n^2.81 > n² ⇒ f(n)=n² 是低阶 ⇒ 情况 1 ⇒ Θ(n^{lg 7})。

**看图说明**：主方法是个「比大小」开关。先算子问题总量 n^{log_b a}，再让 f(n) 跟它比，落到三个分支之一。

## 类比与实例
- **类比**：主方法像工资谈判——a 个子问题是「手下人干活」，f(n) 是「自己做合并」。手下总产量 n^{log_b a} 比 f 大，就由手下决定进度（情况1）；两者一样大，进度乘一层对数（情况2）；自己合并比手下还贵，就由 f 决定（情况3）。**失效边界**：f 与 n^{log_b a} 之间隔着「多项式间隙」才能用主方法；若 f = Θ(n^{log_b a}·lgᵏ n) 这种「差个对数因子」，要用推广版主定理，不能硬套三档。
- **实例**：T(n) = 2T(n/2) + n：log_b a=1，n^1=n 与 f=n 持平 ⇒ 情况 2 ⇒ Θ(n lg n)，与归并排序一致。

## 常见误解
- **别以为主方法对所有递归式都能用**——实际上 f(n) 必须与 n^{log_b a} 是多项式阶可比；像 T(n)=2T(n/2)+n lg n 这种，要用推广版。
- **别以为「n/b 取整」会改变结论**——书中证明取整只影响低阶，渐近结论不变。
- **别以为 Strassen 更快所以日常用它**——实际上常数巨大、数值稳定性差，工程上很少用；它的价值是「矩阵乘法下界可以低于 3」的理论突破。

## 自测题（答案）
1. （单选）T(n) = 9T(n/3) + n，主方法结论是？（答案：A；解析：log_3 9 = 2，n² 比 f=n 高阶 ⇒ 情况 1 ⇒ Θ(n²)）
   - A. Θ(n²)   B. Θ(n² lg n)   C. Θ(n)   D. Θ(n lg n)
2. （单选）T(n) = T(2n/3) + 1（即 a=1,b=3/2）结论是？（答案：B；解析：log_{3/2} 1 = 0，n⁰=1 与 f=1 持平 ⇒ 情况 2 ⇒ Θ(lg n)）
   - A. Θ(1)   B. Θ(lg n)   C. Θ(n)   D. Θ(n²)
3. （填空）Strassen 算法把矩阵乘法递归式写成 T(n)=__T(n/2)+Θ(n²)，复杂度为 Θ(n^lg7)。（答案：7；解析：7 次子矩阵乘法替代 8 次）
4. （简答）最大子数组分治法为什么要单独处理「跨越中点」？（答案：跨越中点的子数组既不属于左半也不属于右半，递归的两个子问题都覆盖不到它；必须在合并阶段用一次线性扫描把它找出来，再与左右最优比三者取最大）

## 复习锚点
- 主方法三档：跟 n^{log_b a} 比大小——低阶取子问题、持平乘 lg、高阶取 f。
- 最大子数组：Θ(n lg n)；Strassen：Θ(n^2.81)。
- 代入法先猜后证；递归树估算层数与每层代价。
