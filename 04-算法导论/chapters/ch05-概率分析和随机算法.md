# 第 5 章：概率分析和随机算法

- **难度**：★★☆ | **预估学时**：2.5 小时 | **前置**：第 2 章；附录 C（计数与概率）

## 学习目标
学完本章，你能：
1. 区分「概率分析」（对输入分布做假设）与「随机算法」（算法自己掷骰子）。
2. 用指示器随机变量快速算出雇用问题的期望雇用次数。
3. 解释生日悖论，算出 k 人时两人生日相同的概率。

## 一句话核心
**当输入不好控制时，让算法自己随机化——期望运行时间就不再依赖最坏输入分布，而由骰子决定。**

## 零基础讲解

### 概念 1：雇用问题（hiring problem）（难度：基础）
你要面试 n 个应聘者，每天看一个人；如果当天这个人比之前所有都好，就「雇用」当前的人（解雇旧的）。问：总雇用次数的期望是多少？
- 最坏情况：应聘者按从差到好排序，每次都雇 ⇒ n 次。
- 假设应聘者以**随机顺序**到来：第 i 个应聘者比前 i-1 个都好的概率 = 1/i。

### 概念 2：指示器随机变量（indicator random variable）（难度：进阶）
**指示器随机变量** I{A}：事件 A 发生取 1，否则取 0（书页公式 5.1）。关键性质（引理 5.1）：E[I{A}] = Pr{A}——事件发生的概率就是它的指示器的期望。

雇用问题：设 Xᵢ = I{第 i 个应聘者被雇用}，X = ΣXᵢ。则 E[Xᵢ] = Pr{第 i 个是前 i 个中最好} = 1/i。
E[X] = Σ E[Xᵢ] = Σ 1/i = ln n + O(1)。**结论**：随机顺序下只期望雇约 ln n 次，而不是 n 次。

### 概念 3：随机化算法（randomized algorithm）（难度：进阶）
雇用问题里我们无法控制输入顺序，于是把输入**随机排列**——算法自己调用 RANDOM 重排数组。典型实现 RANDOMIZE-IN-PLACE(A)：对 i = 1..n，交换 A[i] 与 A[RANDOM(i, n)]。书中证明它产生**均匀随机排列**（每个排列概率 1/n!）。
- **概率分析**：假设输入服从某分布，分析期望。
- **随机算法**：分布不在输入上，而在算法内部——掷骰子决定下一步。

### 概念 4：生日悖论（难度：进阶）
k 个人的屋子里，至少两人生日相同的概率多大？书中设一年 n=365 天。两人生日不同的概率 = 364/365；k 人**全部互不相同**的概率 Π_{i=1}^{k-1}(1 − i/365)。
- k=23 时，至少两人相同的概率就超过 50%——远小于 365。这就是「悖论」：人不需要很多，相同生日就很可能出现。

### 概念 5：球与箱子 / 特征序列 / 在线雇用（难度：高难，了解）
- **球与箱子**：把 n 个球独立随机扔进 b 个箱子，某箱子球数、空箱数的期望。
- **特征序列**：抛硬币 n 次，最长连续正面的期望长度 ≈ lg n。
- **在线雇用**：不能回头、必须当场决定——书中给出「先看约 n/e 个不雇，之后遇到第一个比之前都好的就雇」的策略，雇到最佳者概率 ≈ 1/e。

**看图说明**：随机算法把「输入不可控」变成「算法内部可控」——期望是对骰子取的，不是对恶意输入取的。

## 类比与实例
- **类比**：发牌——不假设牌堆本来就乱，而是洗完牌再发，每个人拿到公平的一手。**失效边界**：随机化不能让「错误算法」变对；它只把最坏输入变成平均输入。
- **实例**：n=1000 应聘者，随机顺序下期望雇用次数 ≈ ln 1000 ≈ 7 次，远少于最坏 1000 次。

## 常见误解
- **别以为「生日悖论说 23 人里有一人跟我同天生日概率 50%」**——实际上它说的是「任意两人之间有一对同天」；跟**你特定**同天要约 253 人才到 50%。
- **别以为「随机算法就是慢」**——实际上快排的随机化版本（第 7 章）期望 Θ(n lg n)，正是靠这一章的随机化思想。
- **别以为「期望 ≈ 平均情况」**——期望是对随机骰子取的平均，可能某次运行很差，但长期平均稳定。

## 自测题（答案）
1. （单选）雇用问题中，第 i 个应聘者被雇用的概率是？（答案：C；解析：他要成为前 i 个中最好，随机顺序下概率 1/i）
   - A. 1/n   B. i/n   C. 1/i   D. 1/2
2. （单选）k=23 人时，至少两人生日相同的概率约为？（答案：B；解析：书中算出约 50.7%，远小于一年天数）
   - A. 6%   B. 50%   C. 99%   D. 0
3. （填空）RANDOMIZE-IN-PLACE 对每个 i，把 A[i] 与 A[__(i, n)] 返回的位置交换。（答案：RANDOM；解析：书中伪代码 A[RANDOM(i,n)]）
4. （简答）概率分析与随机算法的区别？（答案：概率分析假设输入分布并在该分布下分析期望；随机算法在算法内部掷骰子重排/选择，期望对骰子取——不依赖输入是否随机）

## 复习锚点
- 指示器 E[I{A}] = Pr{A}；雇用问题期望 E[X] = H_n ≈ ln n。
- 随机算法 = 算法自己掷骰子；RANDOMIZE-IN-PLACE 生成均匀排列。
- 生日悖论：23 人即有 >50% 出现一对同天。
