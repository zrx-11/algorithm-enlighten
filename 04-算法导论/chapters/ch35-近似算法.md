# 第 35 章：近似算法

- **难度**：★★☆ | **预估学时**：2.5 小时 | **前置**：第 23 章（MST）、第 34 章（NPC）

## 学习目标
学完本章，你能：
1. 说出「近似比（approximation ratio）」的定义，以及为什么 NPC 问题要找近似解。
2. 写出顶点覆盖的 2-近似算法并证明其近似比。
3. 解释 TSP 在三角不等式下的 2-近似（走 MST 遍历），以及为什么无三角不等式时 TSP 近似是 NPC 的。

## 一句话核心
**NPC 问题找不到精确多项式算法时，退而求其次：设计一个算法，保证「解的代价 ≤ α × 最优代价」，α 就是近似比——α 越接近 1 越好。**

## 零基础讲解

### 概念 1：近似算法与近似比（难度：基础）
**近似算法**：对优化问题，输出一个不一定最优、但有「质量保证」的解。
**近似比 ρ(n)**：对任意输入，算法解的代价 C 与最优代价 C* 满足 max(C/C*, C*/C) ≤ ρ(n)（最小化问题看 C/C*，最大化问题看另一侧）。
ρ=1 就是精确算法；ρ=2 表示「坏到不会超过最优的两倍」。

### 概念 2：顶点覆盖的 2-近似（难度：进阶）
算法：
1. 任取一条边 (u,v)。
2. 把 u、v 都加入覆盖集 C。
3. 删去所有与 u 或 v 相连的边。
4. 重复直到无边。
**证明 2-近似**：算法选的边两两不相邻（极大匹配），最优解至少要从每条匹配边里选一个顶点 ⇒ |C*| ≥ |匹配|；而 |C|=2·|匹配| ⇒ |C| ≤ 2|C*|。

### 概念 3：TSP 的 2-近似（三角不等式，难度：进阶）
前提：距离满足三角不等式 d(a,c) ≤ d(a,b)+d(b,c)。
算法：
1. 求图的 MST（第 23 章）。
2. 对 MST 做一次「前序遍历」，把遇到的顶点依次记下来（重复访问同一顶点时直接跳过，走捷径）。
3. 这条遍历顺序就是 TSP 回路。
**为什么是 2-近似**：MST 总权 ≤ 最优 TSP 回路（回路去掉一条边就是生成树）；前序遍历总路程 ≤ 2·MST 总权（每条 MST 边走两次）。故 C ≤ 2·MST ≤ 2·C*。
**重要反面**：若不满足三角不等式，TSP 近似（任意常数比）本身就是 NP 难的——不存在多项式常数近似算法（除非 P=NP）。

### 概念 4：集合覆盖与子集和 FPTAS（难度：高难）
- **集合覆盖的 ln n 近似**：贪心每次选「覆盖最多未覆盖元素」的集合，近似比 ≤ ln n。
- **子集和的完全多项式近似方案（FPTAS）**：给定 ε，把数值「按尺度取整」压缩状态，得到 (1+ε)-近似算法，运行时间关于 1/ε 和输入规模都是多项式的——这是近似算法的「黄金标准」。

**看图说明**：近似比是「质量保证书」；有些问题能轻易拿到 ρ=2，有些问题（如无三角 TSP）连常数近似都 NPC。

## 类比与实例
- **类比**：近似算法像「赶时间吃饭」——找不到全城最优的馆子，但保证「走 10 分钟内一定有吃的，坏也不会比最优贵一倍」。**失效边界**：近似比依赖问题结构；有些问题天生没有常数近似（如无三角 TSP）。
- **实例**：顶点覆盖图 4 条边 (a,b),(b,c),(c,d),(d,a)。算法取 (a,b)，删边；再取 (c,d)，覆盖 {a,b,c,d}；最优也至少要 2 个顶点（如 b,d），4 ≤ 2·2。

## 常见误解
- **别以为「近似算法就是随便给个解」**——实际上它必须有可证明的近似比，是「有保证的启发式」。
- **别以为「所有 NPC 问题都能拿到常数近似」**——实际上无三角 TSP、最大团等问题连常数近似都是 NP 难的。
- **别以为「FPTAS 是精确算法」**——它是 (1+ε)-近似，但运行时间对 1/ε 是多项式的，ε 越小越慢。

## 复习锚点
- 近似比 ρ = 算法解/最优解 的最坏比值。
- 顶点覆盖 ρ=2（极大匹配）；TSP+三角 ρ=2（MST 遍历）。
- 有些问题（无三角 TSP）常数近似本身 NPC；FPTAS 是黄金标准。
