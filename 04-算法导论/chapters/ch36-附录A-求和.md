# 第 36 章：附录 A — 求和

- **难度**：★☆☆ | **预估学时**：1 小时 | **前置**：第 3 章（渐近记号）

## 学习目标
学完本章，你能：
1. 背出并活用等差、等比、平方和三个常用求和公式。
2. 用「积分逼近」估计一个单调递增求和的上界与下界。
3. 用求和公式快速验证递归式的解（如归并排序的 Θ(n lg n)）。

## 一句话核心
**算法分析里反复遇到求和——等差、等比、平方和三张表直接查；拿不准时用「积分夹逼」：单调函数的和一定落在两个相邻积分之间。**

## 零基础讲解

### 概念 1：三张常用求和表（难度：基础）
- **等差级数**：Σ_{k=1}^{n} k = n(n+1)/2 = Θ(n²)。
- **平方和**：Σ_{k=1}^{n} k² = n(n+1)(2n+1)/6 = Θ(n³)。
- **等比级数**：Σ_{k=0}^{n} xᵏ = (x^{n+1}−1)/(x−1)（x≠1）；当 |x|<1 时无穷和 = 1/(1−x)。
白话：算法分析中「循环加 n 次」给出 Θ(n)，「双层循环」给出 Θ(n²)，递归树每层减半给出等比级数 O(n)。

### 概念 2：积分逼近（难度：进阶）
对单调递增函数 f：
∫_{m}^{n+1} f(x) dx ≤ Σ_{k=m}^{n} f(k) ≤ ∫_{m-1}^{n} f(x) dx。
白话：把每一项 f(k) 想成区间 [k,k+1] 上的小矩形面积，求和 ≈ 曲线下的面积。
例：Σ_{k=1}^{n} 1/k（调和数 Hₙ）≈ ln n + O(1)。

### 概念 3：求和与递归树（难度：进阶）
递归式 T(n)=2T(n/2)+n 的递归树：第 j 层代价 n（每层 n），共 lg n 层 ⇒ 总和 n·lg n = Θ(n lg n)。求和工具让你把「每层代价 × 层数」算清楚。

## 类比与实例
- **类比**：求和表像「菜谱」——常见菜直接查；积分逼近像「估算」——拿不准就拿积分当尺子量。**失效边界**：积分逼近要求 f 单调；剧烈振荡的函数不适用。
- **实例**：等比级数 Σ_{j=0}^{lg n} n/2ʲ = n·Σ (1/2)ʲ = n·2 = 2n = O(n)——这是归并排序递归树根层之外的总代价。

## 常见误解
- **别以为「调和数 Hₙ=Σ1/k 是 Θ(lg n)」需要证明**——实际上积分夹逼一步：∫1/x dx = ln n，上下夹出 ln n ± O(1)。
- **别以为「等比级数无穷和一定收敛」**——只有 |x|<1 时收敛；x≥1 时无穷和发散。
- **别以为「求和的渐近界和积分完全一样」**——它们只差 O(1) 或 O(f(n))，但主项相同。

## 自测题（答案）
1. （填空）Σ_{k=1}^{n} k = __。（答案：n(n+1)/2；解析：等差级数）
2. （单选）等比级数 Σ_{k=0}^{∞} (1/2)ᵏ = ？（答案：B；解析：1/(1−1/2)=2）
   - A. 1   B. 2   C. 3   D. ∞
3. （单选）调和数 Hₙ=Σ1/k 的渐近阶是？（答案：C；解析：积分夹逼 ≈ ln n）
   - A. Θ(1)   B. Θ(n)   C. Θ(lg n)   D. Θ(n²)
4. （简答）递归树 T(n)=2T(n/2)+n 的总代价怎么算？（答案：共 lg n 层，每层 n，总和 n·lg n = Θ(n lg n)）

## 复习锚点
- 三表：等差 Θ(n²)、平方 Θ(n³)、等比（|x|<1 收敛）。
- 积分夹逼估计任意单调求和的界。
- 调和数 Hₙ=Θ(lg n)。
