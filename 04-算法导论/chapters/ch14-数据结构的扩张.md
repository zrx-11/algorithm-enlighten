# 第 14 章：数据结构的扩张

- **难度**：★★★ | **预估学时**：2 小时 | **前置**：第 13 章

## 学习目标
学完本章，你能：
1. 说出「数据结构扩张」的标准四步法。
2. 在红黑树每个结点上维护 size 属性，实现 O(lg n) 查第 i 小与查秩。
3. 用区间树快速找出「与给定区间重叠的区间」。

## 一句话核心
**不用发明新结构——在红黑树每个结点上多存一个「子树大小/区间端点」的汇总信息，就能直接得到顺序统计树与区间树。**

## 零基础讲解

### 概念 1：数据结构扩张四步法（书页 §14.2）
1. 选一个基础数据结构（如红黑树）。
2. 在每个结点加一个**新属性**（如 size），并说明这个属性怎么由现有属性算出来。
3. 保证插入/删除时能**维护**这个新属性（旋转时也要更新）。
4. 设计新操作。

### 概念 2：顺序统计树（order-statistic tree）（难度：进阶）
在红黑树每个结点 x 上多加一个属性 **x.size** = 以 x 为根的子树（含 x）的内部结点数。递推式（书页已核对）：
```
x.size = x.left.size + x.right.size + 1
```
- **查询第 i 小（SELECT）**：从根走，根左子树大小 r = left.size。若 i = r+1，根就是第 i 小；i ≤ r 走左；i > r+1 走右并把 i 减去 (r+1)。O(lg n)。
- **查秩（RANK）**：元素 x 在中序遍历中的位置。O(lg n)。

### 概念 3：区间树（interval tree）（难度：高难）
需求：存一组区间（如时间区间），快速找出「与给定区间 [t₁, t₂] 重叠的区间」。
做法：在红黑树里以区间左端点为 key；每个结点 x 多存 **x.max** = 以 x 为根的子树中所有区间右端点的最大值。查找时：若查询区间与 x 重叠就返回 x；否则左子树 max ≥ 左端 → 走左，否则走右。O(lg n)。

## 图示
```mermaid
flowchart LR
    A[基础: 红黑树 O lg n] --> B[每个结点多存 size 或 max]
    B --> C[插入/删除/旋转时同步更新该属性]
    C --> D[新操作: 第i小 / 查秩 / 区间重叠查询]
```
**看图说明**：扩张 = 给老结构加「汇总信息」，而不是推倒重来。size 让树「知道」自己第 i 小；max 让树「知道」哪边可能藏着重叠区间。

## 类比与实例
- **类比**：给组织架构图每个部门标注「本部门共多少人」（size），一眼就能数出全公司第 100 号员工在哪。**失效边界**：加属性后每次旋转/插入都得记得更新，否则 size 过期、答案就错。
- **实例**：顺序统计树根 size=10，左子树 size=4。查第 5 小：5 > 4+1，去右子树找第 5−5=0…（具体按递推）。

## 常见误解
- **别以为「扩张数据结构要从零发明」**——实际上书中的核心方法就是「在红黑树结点上加一个维护好的汇总字段」。
- **别以为「加 size 会让插入变 O(n)」**——实际上 size 只在从根到插入点的路径上变化，每次 O(1) 更新，总 O(lg n)。
- **别以为「区间重叠要两两比」**——实际上 max 属性让查找每次只走一条路径，O(lg n)。

## 自测题（答案）
1. （单选）顺序统计树结点 size 的定义是？（答案：B；解析：x.size = left.size + right.size + 1，含自身）
   - A. 左子树大小   B. 含自身的子树结点数   C. 右子树大小   D. 整棵树结点数
2. （单选）区间树每个结点 x 维护的 max 是什么？（答案：C；解析：子树中所有区间右端点的最大值）
   - A. 左端点最大值   B. 右端点最小值   C. 子树右端点最大值   D. 区间中点
3. （填空）查第 i 小的 SELECT 操作时间是 O(__ n)。（答案：lg；解析：沿一条路径下滑）
4. （简答）旋转时为什么要更新 size？（答案：旋转改变了左右子树结构，size 是子树汇总值；若不更新，后续 SELECT/RANK 读到的 size 是过期的，会给出错误名次）

## 复习锚点
- 扩张四步：选基础结构 → 加属性 → 维护属性 → 设计新操作。
- 顺序统计树：size 字段，O(lg n) 查第 i 小与秩。
- 区间树：max 字段，O(lg n) 查重叠区间。
