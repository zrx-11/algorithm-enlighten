# 第 25 章：所有结点对的最短路径

- **难度**：★★☆ | **预估学时**：2.5 小时 | **前置**：第 24 章、附录 D（矩阵）

## 学习目标
学完本章，你能：
1. 说出「所有结点对最短路」与「单源最短路」的差别，以及为什么不能直接跑 n 遍 Dijkstra。
2. 写出 Floyd-Warshall 的三重循环与它的递推思想。
3. 解释 Johnson 算法如何通过「重赋权」让负权边图也能用 Dijkstra。

## 一句话核心
**想一次问清「任意两点间多远」，Floyd-Warshall 用「中间点编号不超过 k」的递推在 O(V³) 内搞定；Johnson 则先把负权边「洗白」成非负，再跑 n 遍 Dijkstra。**

## 零基础讲解

### 概念 1：邻接矩阵与递归表示（难度：基础）
所有结点对问题用矩阵 W=(wᵢⱼ) 表示（wᵢᵢ=0，无边为 ∞）。设 D⁽ᵏ⁾ᵢⱼ = i 到 j、**中间经过的顶点编号 ≤ k** 的最短路。递推：
- 不经过 k：D⁽ᵏ⁾ᵢⱼ = D⁽ᵏ⁻¹⁾ᵢⱼ
- 经过 k：D⁽ᵏ⁾ᵢⱼ = D⁽ᵏ⁻¹⁾ᵢₖ + D⁽ᵏ⁻¹⁾ₖⱼ
- 取较小者。k 从 0 到 |V|。

### 概念 2：Floyd-Warshall（难度：进阶）
```
for k = 1..n
  for i = 1..n
    for j = 1..n
      d[i][j] = min(d[i][j], d[i][k] + d[k][j])
```
复杂度 **Θ(n³)**，自动处理负权边（但不允许负权回路）。还能同步求「前驱矩阵 π」还原路径。
白话：允许中转站的编号从小到大，每放开一个新中转站 k，就看看「先到 k 再出发」有没有更短的路。

### 概念 3：基于矩阵乘法的慢算法（难度：进阶）
把「最短路径」看成一种特殊的矩阵乘法（把 × 换成 +，把 + 换成 min）。每「乘」一次相当于路径多松弛一步，乘 ⌈log n⌉ 次即可，复杂度 O(n³ log n)——比 Floyd-Warshall 慢，仅作思路演示。

### 概念 4：Johnson 算法（难度：高难）
思路分两步：
1. **重赋权（reweight）**：用 Bellman-Ford 加一个虚拟源点，算出每个顶点的势能 h(v)，令 w̃(u,v)=w(u,v)+h(u)−h(v)。关键结论：这样得到的新权 w̃(u,v) **全部非负**，且任意两点间最短路不变（路径上的 h 项首尾相消）。
2. 对每个顶点跑一遍 Dijkstra，得到用 w̃ 的最短路，再把 h 项还原回真实距离。
复杂度 **O(V² lg V + VE)**，稀疏图上比 Floyd-Warshall 快。

## 图示
```mermaid
flowchart TD
    A[任意两点最短路] --> B{图有负权边?}
    B -->|稠密/简单| C[Floyd-Warshall: 三重循环 O(n³)]
    B -->|稀疏且有负权边| D[Johnson: 势能重赋权洗白成非负 → 跑 V 遍 Dijkstra]
    C --> E[d[i][k]+d[k][j] 与 d[i][j] 取小]
    D --> F[w̃=w+h[u]-h[v], 路径上 h 相消]
```
**看图说明**：Floyd-Warshall 靠「放开中转站」的递推；Johnson 靠「换一把不扭曲长短的尺子」（势能）把负权边问题变成 Dijkstra 能解的样子。

## 类比与实例
- **类比**：Floyd-Warshall 像做「全国任意两城最短距离表」——每开放一个新枢纽机场，就更新一次「经此枢纽是否更快」。**失效边界**：有负权回路时距离会趋于 −∞，算法无意义。
- **实例**：三顶点 a→b=3、b→c=1、a→c=10。k=b 时 d[a][c] 从 10 被刷新为 d[a][b]+d[b][c]=4。

## 常见误解
- **别以为「所有结点对问题 = 跑 n 遍 Bellman-Ford」**——那是 O(n²·n) = O(n³·… ) 中最慢的一档；Floyd-Warshall 同样 O(n³) 但常数小得多，Johnson 在稀疏图更快。
- **别以为「重赋权会改变最短路」**——实际上 w̃ 上的最短路和 w 上的最短路一一对应，因为路径首尾的 h(u)−h(v) 会消掉。
- **别以为「Floyd-Warshall 要先拓扑排序」**——它不要求 DAG，普通有向图直接三重循环。

## 自测题（答案）
1. （单选）Floyd-Warshall 的运行时间是？（答案：C；解析：三重循环 Θ(n³)）
   - A. O(n²)   B. O(VE)   C. Θ(n³)   D. O(n³ log n)
2. （单选）Johnson 算法把负权边图变成非负图靠的是？（答案：B；解析：用势能 h 重赋权 w̃=w+h[u]−h[v]）
   - A. 删边   B. 势能重赋权   C. 拓扑排序   D. 取绝对值
3. （填空）Floyd-Warshall 的递推里，d[i][j] = min(d[i][j], __)。（答案：d[i][k]+d[k][j]；解析：经过中转站 k）
4. （简答）为什么重赋权 w̃(u,v)=w(u,v)+h(u)−h(v) 不改变最短路径？（答案：对任意路径 i→j，w̃ 求和时 +h(i)−h(j) 是常数差，路径之间的大小关系不变）

## 复习锚点
- Floyd-Warshall：放开中转站 k，O(n³)，容负权边不容负权回路。
- Johnson：先势能重赋权洗白成非负，再每点跑 Dijkstra，稀疏图更优。
- 重赋权的代数本质：路径首尾 h 项相消，最短距离关系不变。
