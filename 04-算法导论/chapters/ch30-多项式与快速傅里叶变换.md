# 第 30 章：多项式与快速傅里叶变换

- **难度**：★★★ | **预估学时**：3.5 小时 | **前置**：复数幂、附录 A（求和）

## 学习目标
学完本章，你能：
1. 说出多项式的「系数表示」与「点值表示」，以及为什么乘积在点值表示下更快。
2. 写出 FFT 的分治思想（奇偶分组），说出它把 DFT 从 O(n²) 降到 O(n lg n)。
3. 复述「系数 → 点值 → 乘积点值 → 逆 DFT → 乘积系数」整条流水线。

## 一句话核心
**普通多项式乘法是 O(n²)；FFT 把「求 n 个点的取值」这件事从 O(n²) 压到 O(n lg n)，于是整条乘法流水线（系数→点值→点乘→逆变换）只要 O(n lg n)。**

## 零基础讲解

### 概念 1：多项式的两种表示（难度：基础）
- **系数表示**：A(x)=a₀+a₁x+…+a_{n-1}x^{n-1}，存 n 个系数。
- **点值表示**：选 n 个不同点 x₀,…,x_{n-1}，存 (xₖ, A(xₖ)) 对。n 个点值唯一确定一个 n−1 次多项式（插值定理）。
为什么点值表示好？乘积 C(x)=A(x)B(x) 在点值下就是对应点值直接相乘：C(xₖ)=A(xₖ)·B(xₖ)，O(n) 搞定。

### 概念 2：DFT 与单位复根（难度：进阶）
**离散傅里叶变换（DFT）**：给定系数，求它在 n 个 n 次单位复根 ωₖ = e^{2πik/n} 上的取值。
朴素求每个点值 O(n)，n 个点 O(n²)。但单位复根有个关键性质 ωₖ² = (n/2) 次单位复根——这给了分治的机会。

### 概念 3：FFT 分治（难度：高难）
把 A(x) 按奇偶系数拆开：
- A⁽⁰⁾(x) = a₀ + a₂x + a₄x²+…（偶次项）
- A⁽¹⁾(x) = a₁ + a₃x + a₅x²+…（奇次项）
则 A(x) = A⁽⁰⁾(x²) + x·A⁽¹⁾(x²)。
递归求 A⁽⁰⁾、A⁽¹⁾ 在 (ωₖ)² 这些 n/2 次根上的点值，再组合。复杂度递推 T(n)=2T(n/2)+O(n) ⇒ **O(n lg n)**。
**逆 DFT**：把 ω 换成 ω⁻¹、结果除以 n，同样用 FFT。

### 概念 4：完整乘法流水线（难度：进阶）
```
A、B 系数表示
  → FFT 求各自在 n 个单位根上的点值（补到 2n 长度）
  → 对应点值相乘得 C 的点值（O(n)）
  → 逆 FFT 把 C 的点值变回系数
```
总复杂度 **O(n lg n)**，远好于朴素 O(n²)。用途：大整数乘法、信号处理、卷积。

**看图说明**：瓶颈不在「点乘」（O(n)），而在「系数↔点值」的转换；FFT 把这一步从 O(n²) 降到 O(n lg n)，整条流水线就快了。

## 类比与实例
- **类比**：系数表示像「给一个人量身高体重」（要算），点值表示像「拍一组照片」（直接看）。乘法在「照片」空间里就是逐张照片相乘，再拍回来。**失效边界**：n 必须是 2 的幂（否则补零到最近的 2 的幂）。
- **实例**：A(x)=1+2x，B(x)=3+4x。乘积 C=3+10x+8x²。在点值 x=1 处 A(1)=3、B(1)=7，C(1)=21=3+10+8，对得上。

## 常见误解
- **别以为「FFT 是用来做信号处理的，跟算法课无关」**——实际上它的本质是多项式快速乘法，信号处理只是其应用。
- **别以为「任意 n 都能直接 FFT」**——标准 Cooley-Tukey FFT 要求 n 是 2 的幂，否则补零。
- **别以为「点值表示比系数表示省空间」**——两者都是 n 个数；省的是「乘法」的时间，不是空间。

## 自测题（答案）
1. （单选）FFT 把 DFT 的复杂度从 O(n²) 降到？（答案：C；解析：分治递推 T(n)=2T(n/2)+O(n)）
   - A. O(n)   B. O(n lg lg n)   C. O(n lg n)   D. O(n^{1.5})
2. （单选）两个多项式乘积在点值表示下怎么算？（答案：A；解析：对应点值直接相乘）
   - A. 对应点值相乘   B. 系数相加   C. 求导   D. 积分
3. （填空）FFT 分治利用了 ωₖ² 是__次单位复根的性质。（答案：n/2；解析：奇偶分组递归）
4. （简答）为什么逆 FFT 也是 FFT？（答案：把变换核 ω 换成 ω⁻¹ 再除以 n，分治结构完全一样）

## 复习锚点
- 系数表示 ↔ 点值表示；乘积在点值下 O(n)。
- FFT 分治：奇偶拆分，O(n lg n)。
- 整条乘法流水线：FFT→点乘→逆 FFT，O(n lg n)。
