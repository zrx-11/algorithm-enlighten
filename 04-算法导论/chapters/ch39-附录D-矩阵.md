# 第 39 章：附录 D — 矩阵

- **难度**：★☆☆ | **预估学时**：1 小时 | **前置**：第 28 章（矩阵运算）

## 学习目标
学完本章，你能：
1. 说出矩阵加、乘、转置、逆的定义与基本性质。
2. 用行列式判断矩阵是否可逆。
3. 复述单位矩阵、对称矩阵、正定矩阵的判别。

## 一句话核心
**矩阵是「把一组线性方程打包」的工具——乘是「行乘列」、逆是「反变换」、行列式为 0 就是「信息丢失、不可逆」；第 28 章的 LUP 分解就是把这些操作算快。**

## 零基础讲解

### 概念 1：矩阵运算（难度：基础）
- **矩阵加法**：同尺寸矩阵对应元素相加。
- **矩阵乘法**：C=AB，Cᵢⱼ = Σₖ Aᵢₖ Bₖⱼ（A 的行 × B 的列）。不满足交换律（一般 AB≠BA）。
- **转置 Aᵀ**：行变列、列变行。(AB)ᵀ=BᵀAᵀ。
- **单位矩阵 I**：对角线为 1、其余为 0；AI=IA=A。

### 概念 2：逆与行列式（难度：进阶）
**逆矩阵 A⁻¹**：满足 AA⁻¹=A⁻¹A=I。
**可逆 ⇔ det(A)≠0**（行列式非零）。
**行列式 det(A)**：对 2×2 是 ad−bc；高阶用递归展开。det=0 意味着「A 把空间压成了低维」，信息丢失，无法反变换。

### 概念 3：特殊矩阵（难度：进阶）
- **对称矩阵**：A=Aᵀ。
- **对称正定矩阵**：A=Aᵀ 且对任意非零 x 有 xᵀAx>0；可逆、所有主元为正、可 Cholesky 分解 A=LLᵀ（见第 28 章）。
- **对角矩阵**：非对角元为 0。

**看图说明**：矩阵运算的「原子」是加法、乘法、转置；逆与行列式绑定；正定是数值稳定的好性质。

## 类比与实例
- **类比**：矩阵像「一段剪辑变换」——乘是「先做 B 再做 A」的组合，逆是「倒放」，行列式为 0 是「这段剪辑把画面压扁成一条线，倒不回去了」。**失效边界**：矩阵乘法不交换，AB≠BA，顺序很重要。
- **实例**：A=[[1,2],[3,4]]，det=1·4−2·3=−2≠0 ⇒ 可逆；A⁻¹ = (−1/2)[[4,−2],[−3,1]]。

## 常见误解
- **别以为「矩阵乘法交换」**——实际上一般 AB≠BA，甚至 AB 与 BA 尺寸不同。
- **别以为「det=0 只是巧合」**——实际上它意味着线性相关，是「不可逆」的代数信号。
- **别以为「对称矩阵就是对角矩阵」**——实际上对称只要求 A=Aᵀ，非对角元可以非零。

## 自测题（答案）
1. （单选）矩阵 A 可逆当且仅当？（答案：B；解析：det(A)≠0）
   - A. A=Aᵀ   B. det(A)≠0   C. A 全为正   D. A 是方阵
2. （单选）(AB)ᵀ = ？（答案：C；解析：转置反序）
   - A. AᵀBᵀ   B. ABᵀ   C. BᵀAᵀ   D. BA
3. （填空）对称正定矩阵对任意非零 x 满足 xᵀAx __ 0。（答案：>；解析：正定定义）
4. （简答）为什么 det(A)=0 意味着不可逆？（答案：行列式为 0 表示 A 的列向量线性相关，A 把空间压成低维，不同 x 映到同一像，无法定义逆）

## 复习锚点
- 矩阵乘 = 行乘列，不交换。
- 可逆 ⇔ det≠0。
- 对称正定：A=Aᵀ 且 xᵀAx>0，数值稳定、免选主元。
