# 动态规划与贪心

- **难度**：高难 | **涉及章节**：第 14、15 章

## 一句话定义
DP 保留所有可能状态再择优，贪心只选当前一步最优——后者更简单更快，但必须满足贪心选择性质。

## 为什么重要
它们都解最优化问题；选错（该 DP 用贪心）会得到次优甚至很差的解。

## 图示
```mermaid
flowchart LR
    DP[DP: 记录所有状态<br>dp[i][c] 取 max] --> Sol[最优解]
    GR[贪心: 每步局部最优<br>不回看] --> Sol
```
**看图说明**：DP 权衡多条路；贪心一条路走到底。

## 详解
- **DP**：考虑过去所有决策，状态转移填表；适合无后效性的重叠子问题。
- **贪心**：不回看，每步选局部最优；前提是贪心选择性质 + 最优子结构。
- **取舍**：证明不了贪心选择性质时，用 DP 兜底。零钱兑换是经典反例。

## 常见误解
- 别以为代码短的贪心就对——实际上零钱兑换在 [1,20,50] 下贪心得到 11 枚，DP 只要 3 枚。
- 别以为贪心一定比 DP 差——实际上满足性质时，贪心 O(n) 完胜 DP 的 O(n·cap)。
