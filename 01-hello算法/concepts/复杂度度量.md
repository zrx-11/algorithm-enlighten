# 复杂度度量（大 O 记号）

- **难度**：基础 | **涉及章节**：第 2 章，并贯穿全书

## 一句话定义
复杂度度量是"当输入规模 n 变大时，算法运行时间或内存占用大致涨多快"的数学尺子，用大 O 记号表示。

## 为什么重要
它是全书判断"哪个算法更好"的统一语言。没有它，你只能凭感觉说"这个快那个慢"；有了它，才能客观比较排序、搜索、DP 之间的取舍。

## 详解
- **时间复杂度**：数基本操作随 n 的增长。常见阶序：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)。
- **空间复杂度**：额外内存随 n 的增长。O(1) 是原地，O(n) 需开数组或深递归。
- 大 O 只管 n 很大时的上界趋势；n 很小时常数项可能主导（插入排序反而比快排快）。

## 常见误解
- 别以为大 O 是精确秒数——实际上它丢系数、丢低阶项。
- 别以为递归一定比循环慢——实际上斐波那契递归慢是因为重复子问题（O(2ⁿ)），不是递归本身。
