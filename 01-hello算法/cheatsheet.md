# 速查表

## 复杂度阶序（从快到慢）
O(1) 常数 < O(log n) 对数 < O(n) 线性 < O(n log n) < O(n²) 平方 < O(2ⁿ) 指数 < O(n!) 阶乘

## 排序算法对比
| 算法 | 平均 | 空间 | 稳定 | 关键特性 |
|---|---|---|---|---|
| 冒泡 | O(n²) | O(1) | 是 | flag 后最佳 O(n) |
| 选择 | O(n²) | O(1) | 否 | 总 O(n²) |
| 插入 | O(n²) | O(1) | 是 | 小数据最快 |
| 快速 | O(n log n) | O(n) | 否 | 实际最快，最坏O(n²) |
| 归并 | O(n log n) | O(n) | 是 | 稳定，需辅助数组 |
| 堆 | O(n log n) | O(1) | 否 | 原地 |
| 桶/计数/基数 | O(n+k) | O(n+k) | 视实现 | 非比较，范围受限 |

## 经典问题解法速记
| 问题 | 方法 | 核心 |
|---|---|---|
| 爬楼梯 | DP | dp[i]=dp[i-1]+dp[i-2] |
| 最小路径和 | DP | dp[i][j]=min(上,左)+grid[i][j] |
| 0-1 背包 | DP | max(不拿, 拿)；一维倒序 |
| 完全背包 | DP | 一维正序 |
| 编辑距离 | DP | 末尾相同继承左上，否则三者min+1 |
| 全排列 | 回溯 | selected 剪枝 |
| 子集和 | 回溯 | start 去重 + 排序剪枝 |
| n 皇后 | 回溯 | 行列/双斜线三数组剪枝 |
| Top-k | 堆 | 大小 k 的小顶堆 |
| 最大容量 | 贪心 | 双指针移短板 |

## Python 常用工具

- 堆：`heapq.heappush()` / `heappop()`
