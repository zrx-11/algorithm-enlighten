# 第 11 章：排序

- **难度**：★★★ | **预估学时**：4 小时 | **前置**：第 4 章、第 8 章、第 10 章

## 学习目标
学完本章，你能：
- 说清评价排序算法的五个维度；
- 列出常见排序算法的复杂度与稳定性；
- 解释快排为什么快、归并为什么稳；
- 知道桶/计数/基数排序为什么能达到线性。

## 一句话核心
排序把混乱数据变有序；评价它看运行效率、原地性、稳定性、自适应性、是否基于比较——没有一种算法全胜。

## 零基础讲解
### 概念 1：评价维度（难度：基础）
评价排序算法看五点：
1. **运行效率**：时间复杂度尽量低；
2. **原地性**：能否不开额外数组直接在原数组上排；
3. **稳定性**：相等元素排序后相对顺序不变；
4. **自适应性**：能否利用已有顺序加速；
5. **是否基于比较**：基于比较的排序理论最优 O(n log n)。

### 概念 2：O(n²) 家族（难度：基础）
- **冒泡排序**：相邻两两比较交换，大的一步步"冒"到末尾。加 flag 后最佳 O(n)。稳定、原地。
- **选择排序**：每轮选最小放到已排序末尾。不稳定、原地。
- **插入排序**：像整理手牌，把新元素插入已排序段的正确位置。数据量小时最快，稳定、原地。

### 概念 3：O(n log n) 家族（难度：进阶）
- **快速排序**：选基准 pivot，把比它小的放左、大的放右（哨兵划分），再递归两边。平均 O(n log n)，最坏 O(n²)（可用三数取中/随机基准避免）。缓存友好所以实际很快。不稳定、原地。
- **归并排序**：先对半拆到单元素，再两两合并成有序段。稳定、O(n log n)，但要 O(n) 辅助数组。
- **堆排序**：建成大顶堆后反复把堆顶换到底部并堆化。原地 O(n log n)，不稳定。

### 概念 4：线性排序（难度：高难）
不基于比较，可达 O(n)：
- **桶排序**：把数据分到若干桶，桶内各自排序再合并；
- **计数排序**：统计每个数字出现次数，天然有序回填（适合数据量大、范围小的非负整数）；
- **基数排序**：按低位到高位逐位做计数排序（学号、定长数字）。

## 排序算法对比表
| 算法 | 平均时间 | 空间 | 稳定 | 备注 |
|---|---|---|---|---|
| 冒泡 | O(n²) | O(1) | 是 | flag 后最佳 O(n) |
| 选择 | O(n²) | O(1) | 否 | 总是 O(n²) |
| 插入 | O(n²) | O(1) | 是 | 小数据量最快 |
| 快速 | O(n log n) | O(n) 栈 | 否 | 实际最快 |
| 归并 | O(n log n) | O(n) | 是 | 稳定，需辅助数组 |
| 堆 | O(n log n) | O(1) | 否 | 原地 |
| 桶/计数/基数 | O(n+k) | O(n+k) | 视实现 | 非比较 |

## 类比与实例
- 类比：排序像整理扑克牌——插入排序就是理手牌；快速排序像把牌按"比某张小/大"分成两堆再各自理。**失效边界**：扑克牌能随手抽，数组划分要严格按位置。
- 实例：稳定排序是多级排序的前提——先按姓名排，再按年龄排；若不稳定，相同年龄的人姓名顺序会被打乱。

## 常见误解
- 别以为"快排永远最快"——实际上它最坏 O(n²)，靠基准优化把坏情况概率压低。
- 别以为 O(n log n) 一定比 O(n²) 快——实际上 n 很小时插入排序因常数小反而更快，Java/Python 内置排序在短区间就回退到插入排序。
- 别以为线性排序通用——实际上计数/基数排序要求数据能映射成小范围非负整数。

## 自测题（答案）
1. （单选）下列哪种排序是稳定的？ A. 快速排序 B. 选择排序 C. 归并排序 D. 堆排序（答案：C；解析：归并合并时相等元素次序保持。）
2. （填空）基于比较的排序，理论最优时间复杂度是______。（答案：O(n log n)；解析：这是比较排序的下界。）
3. （单选）数据量小、且基本有序时，通常最快的是？ A. 归并排序 B. 插入排序 C. 堆排序 D. 基数排序（答案：B；解析：插入排序自适应+常数小。）
4. （判断）计数排序适合任意类型数据。（答案：错误；解析：它要求数据是可映射的小范围非负整数。）
5. （简答）为什么多级排序必须用稳定排序？（答案：不稳定会打乱上一级已经排好的同键元素相对顺序，破坏多级结果。）

## 复习锚点
- 五维度：效率/原地/稳定/自适应/是否基于比较。
- O(n²)：冒泡、选择、插入；O(n log n)：快排、归并、堆排。
- 线性：桶、计数、基数（非比较、范围受限）。
