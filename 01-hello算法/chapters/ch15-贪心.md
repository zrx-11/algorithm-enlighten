# 第 15 章：贪心

- **难度**：★★☆ | **预估学时**：2 小时 | **前置**：第 14 章

## 学习目标
学完本章，你能：
- 说清贪心算法的基本思想；
- 判断贪心选择性质是否成立；
- 用贪心解分数背包、最大容量、最大切分乘积；
- 知道贪心与 DP 的取舍。

## 一句话核心
贪心每一步都选"当前看起来最好"的局部最优，不回头——只要问题有贪心选择性质，它就是又快又简单的最优解。

## 零基础讲解
### 概念 1：贪心（greedy algorithm）（难度：基础）
**贪心算法**在每个决策阶段，只选当前最划算的一步，一路向前，期望拼出全局最优解。它不回看历史决策，比 DP 更轻。

### 概念 2：两个前提（难度：进阶）
贪心要保证得到最优解，问题须满足：
1. **贪心选择性质**：每步局部最优选择最终能通向全局最优；
2. **最优子结构**：原问题最优解包含子问题最优解。

零钱兑换反例：硬币 [1,20,50]、目标 60，贪心选 50+10×1（11 枚），但 DP 能找到 20+20+20（3 枚）——说明该硬币组合下贪心选择性质不成立。

### 概念 3：典型例子（难度：进阶）
- **分数背包**：物品可拆分，按"单位价值 = 价值/重量"从高到低装，装不下就按比例补满。反证法可证明贪心最优。
- **最大容量（盛水容器）**：双指针从两端向内，每次移动短板（动长板面积一定更小），O(n)。
- **最大切分乘积**：把 n 拆成若干正整数使乘积最大——尽量拆成 3（3+3 优于 2+2+2），余数为 1 时换成 2+2。

**看图说明**：与 DP 的区别——贪心每步只选一个方向、不保留其他分支；DP 会保留所有可能状态再择优。

## 类比与实例
- 类比：贪心像"走路只选眼前最陡上坡"——有时能登顶（简单凸问题），有时会困在小山包上错过主峰（贪心选择性质不成立）。**失效边界**：遇到需要回头权衡的问题，贪心就不是最优。
- 实例：分数背包——先装最值钱/单位重量的物品，剩余容量按比例取次优物品，得到全局最大价值。

## 常见误解
- 别以为贪心代码短就一定对——实际上它常常"部分正确"，必须用反例检验或数学证明。
- 别以为贪心和 DP 是竞争关系——实际上对满足贪心选择性质的问题，贪心是 DP 的高效近似；否则老实用 DP。

## 自测题（答案）
1. （单选）贪心算法与 DP 的核心区别是？ A. 贪心不回头选局部最优，DP 保留多状态择优 B. 贪心只能解排序 C. DP 不做决策 D. 二者完全相同（答案：A；解析：贪心每步一条路，DP 记录所有可能。）
2. （填空）贪心保证最优解需要______性质和最优子结构。（答案：贪心选择；解析：局部最优能通向全局最优。）
3. （单选）分数背包的贪心策略是按什么从高到低装？ A. 重量 B. 价值 C. 单位价值（价值/重量） D. 体积（答案：C；解析：单位价值最高者优先。）
4. （判断）零钱兑换在任何硬币组合下贪心都最优。（答案：错误；解析：如 [1,20,50] 凑 60 时贪心得到 11 枚，最优是 3 枚。）

## 复习锚点
- 贪心 = 每步局部最优、不回看。
- 前提：贪心选择性质 + 最优子结构。
- 经典：分数背包、最大容量（双指针移短板）、最大切分乘积（尽量拆 3）。
