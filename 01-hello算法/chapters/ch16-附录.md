# 第 16 章：附录（环境与术语速览）

- **难度**：★☆☆ | **预估学时**：0.5 小时 | **前置**：全书

## 学习目标
学完本章，你能：
- 搭好本书推荐的 VS Code + Python 环境；
- 掌握算法与数据结构核心术语的中英文对照；
- 知道本书是开源项目、可以参与贡献。

## 一句话核心
附录是"工具箱说明书 + 术语对照表"，让你把代码跑起来、把术语叫准确。

## 零基础讲解
### 概念 1：编程环境（难度：基础）
推荐 **VS Code** 作为编辑器，安装 Python 扩展包；Python 建议 3.10 以上。本书所有代码都能在这个环境里直接运行调试。可选装 `black` 做代码格式化。

### 概念 2：核心术语速览（难度：基础）
| 英文 | 中文 |
|---|---|
| algorithm | 算法 |
| data structure | 数据结构 |
| time/space complexity | 时间/空间复杂度 |
| recursion / iteration | 递归 / 迭代 |
| array / linked list | 数组 / 链表 |
| stack / queue / deque | 栈 / 队列 / 双向队列 |
| hash table / collision | 哈希表 / 哈希冲突 |
| binary tree / BST | 二叉树 / 二叉搜索树 |
| heap / priority queue | 堆 / 优先队列 |
| graph / BFS / DFS | 图 / 广度优先搜索 / 深度优先搜索 |
| binary search | 二分查找 |
| sorting（quick/merge/heap/bucket/counting/radix）| 排序（快/归并/堆/桶/计数/基数）|
| divide and conquer / backtracking | 分治 / 回溯 |
| dynamic programming | 动态规划 |
| greedy algorithm | 贪心算法 |

### 概念 3：开源协作（难度：基础）
本书是开源项目，发现笔误可在 GitHub 上提 Pull Request 修正——这也是巩固学习的一种方式。

## 类比与实例
- 类比：附录像"家电说明书的最后几页"——平时不看，真要配环境/查名词时翻它。
- 实例：看到英文文献里 "knapsack problem"，查表即知是"背包问题"。

## 常见误解
- 别以为环境配置不重要——实际上跑不起来代码，算法学习就是纸上谈兵。
- 别以为术语中文叫法就够——实际上看英文资料时，算法术语英文是绕不开的。
